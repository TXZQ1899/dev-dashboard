# 服务器资源全景

入口 `/resources`。以当前版本的 DevOps、ECS、JumpServer IP 并集构建宽表，版本切换或同步后随四份原有快照重新生成，无单独的缓存或更新步骤。

- IP 逐地址匹配，公网与内网地址分开；按 IP 去重不等于按物理机器去重。
- 公司机房范围由用户确认：`10.58.0.0/16`。有 ECS 精确匹配的标为阿里云；如果与机房网段重叠，另行提示冲突。其余地址类型留空，不以“未匹配阿里云”推断机房。
- JumpServer 覆盖为当前账号资产 IP 的精确匹配。缺失统计的分母是 DevOps 与 ECS IP 并集，不以账号不可见推断实际未纳管。
- 其他 ECS 地址已纳管只作附加提示，不算当前 IP 已覆盖，也不将那个地址的 JumpServer 分组或应用复制过来。
- 同 IP 多条 JumpServer 资产记录保留各自最细分组路径；父分组仅在没有更细匹配时保留。ECS 同 IP 多实例保留全部项目，并提示核对 VPC。
- 应用关联按应用 ID、环境、端口、Git 完整地址区分；同一组合多个部署记录取最新非空 Push In 时间。Git 优先使用部署配置，缺少时回退应用默认 Git；端口同理。
- Codeup 代码组由完整 Git 地址映射，保持仓库路径大小写和主机名边界，支持 HTTP/HTTPS/SSH 地址规范化，不根据同名仓库关联。
- 宽表字段无值就留空。每个 IP 默认显示前五项部署关联，可展开；四个应用相关列逐行对应。25 个 IP 一页，筛选重置页码。

验证：`npm test` 中的 `tests/resource-comparison.test.cjs` 包含并集去重、覆盖分母、公私网别名、机房网段、分组层级、应用/Git/Push In 对齐、冲突提示和筛选组合。
